# Personal-Projects-Dashboards
PowerBI and Tableau Projects

This repository is a personal learning project where I explore Power BI, Tableau, and data visualization techniques. 
The datasets and dashboards here are created for practice, experimentation, and skill-building.
Some inspirations for these visualizations come from real-world company dashboards, online tutorials, and industry best practices.
However, all the work shared here is built by me from scratch as part of my journey to improve my skills in data analytics and storytelling.

I genuinely enjoy exploring different datasets, creating interactive dashboards, and applying BI tools to solve analytical problems. 
If you have feedback or suggestions, I’d love to connect and discuss!
